# Sistemas Multiagente

Repo del curso de Sistemas Multiagente — ORT Uruguay.

## Estructura

- `diapositivas/` — slides del curso
- `practicos/` — trabajos prácticos (notebooks, scripts)
- `obligatorio/` — obligatorio del curso (consigna + código)
- `parciales/` — parciales y soluciones (2020-2023)
- `material_complementario/` — papers y libros de referencia
- `clases/` — grabaciones de clases (no trackeadas por tamaño)
- `transcripciones/` — apuntes de clase en texto
